SentinelSec

Reglas del Juego – ¡Conviértete en analista SOC!

🎯 Objetivo General

Eres analista Tier 1 → Tier 2 → Tier 3 de un SOC.
Tu misión es analizar alertas de seguridad y tomar decisiones rápidas y correctas bajo presión.

Progresión de Niveles y Dificultad

El juego tiene 3 niveles con mecánicas y complejidad creciente:

🔹 Nivel 1 – Alert Triage Básico (Tier 1 – Junior)

  • Recibes una alerta cada vez (hasta 20 alertas).
  • Decides: Escalar o No Escalar.
  • Hay alertas Low / Medium / High con diferente probabilidad de ser reales.
  • Información disponible:
    • Nombre de la alerta
    • Severidad
    • Actividad observada (con IP y hora aleatoria)
    • Contexto adicional
    • Host, usuario, departamento, SO
  • Clave: Aprender a distinguir ruido rutinario (copias de seguridad, actualizaciones, inicios de sesión normales) de señales de compromiso reales (C2, ransomware, exfiltración, PowerShell sospechoso, etc.).
  • Errores cuestan 1 vida. Aciertos dan +25 puntos.
  • Fin: 0 vidas o 20 alertas respondidas.

Objetivo pedagógico: Desarrollar intuición inicial de triage y reducir falsos negativos graves.

🔸 Nivel 2 – Correlación de Alertas (Tier 1 avanzado / Tier 2 inicial)

  • Ahora recibes dos alertas simultáneas en cada ronda.
  • Tienes que decidir si:
    • Coinciden / están relacionadas (mismo atacante, misma campaña, misma víctima)
    • No coinciden (una es ruido / falso positivo o son incidentes independientes)
  • Las alertas pueden compartir:
    • Usuario
    • Host
    • IP (no siempre)
    • Departamento
  • ~45% de las rondas son correlacionadas (mismo contexto), el resto son independientes o una es ruido legítimo.
  • Incluye muchas más señales de High severity (ransomware, C2, exfiltración masiva, beaconing, dumping de credenciales, movimiento lateral…)
  • También hay falsos positivos realistas (actualizaciones, backups, RDP legítimo, Defender, etc.).
  • Misma puntuación: +25 acierto, -1 vida error.

Objetivo pedagógico: Entrenar correlación de eventos y reducir ruido mediante contexto compartido.

🔴 Nivel 3 – Respuesta Rápida a Incidentes (Tier 2 / Tier 3)

  • Cada ronda es un escenario realista de incidente (no solo triage, sino decisión de contención).
  • Recibes:
    • Resumen de alerta
    • Varios logs relacionados (Sysmon, Windows Event, red…)
  • Tienes que elegir acciones de respuesta inmediata (puedes seleccionar varias):
    • Aislar host (isolate)
    • Bloquear IP (blockip)
    • Matar proceso (kill)
    • Poner en cuarentena archivo (quarantine)
    • Resetear contraseñas (reset)
    • Recolectar artefactos (collect)
    • Reportar / escalar (report)
    • Marcar como falso positivo / ajustar regla (false / tune)
    • Monitorizar solamente (monitor)
    • Investigar más (investigate)
  • Cada escenario tiene una combinación correcta (o varias aceptables).
  • Ejemplos de escenarios:
    • Phishing → PowerShell codificado → C2
    • Password spraying
    • Web shell en IIS
    • Ransomware cifrando + eliminación de shadows
    • Mimikatz / lsass access
    • Certutil como downloader
    • Insider exfiltrando a mega.nz
    • Macro maliciosa Office
    • Falsos positivos: backup legítimo, PsExec admin, actualización Defender

Objetivo pedagógico: Pasar de “¿escalamos?” a “¿qué hacemos YA?” – priorizar contención y respuesta.

🧮 Sistema de Puntuación (todos los niveles)

  • Acierto → +25 puntos
  • Error → -1 vida
  • Empiezas con 3 vidas

🏆 Rangos (acumulativo en todos los niveles)

  • 0–100 → Junior Analyst
  • 101–200 → Intermediate Analyst
  • 201–300 → Senior Analyst
  • 301–400 → Threat Hunter Pro
  • 401+ → SOC Master

🏁 Fin del Juego

El juego termina cuando:

  • Pierdes las 3 vidas
  • Completas todas las rondas del nivel (en nivel 1 son 20)

Verás tu puntuación final, rango y podrás volver a jugar o salir.
